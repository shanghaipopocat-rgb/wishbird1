# 3D 可折疊 SVG 包裝盒展示器

## 一、專案目標

建立一個純前端、可離線執行的 3D 包裝盒展示工具。

主要用途是將既有的包裝設計 SVG／PNG／JPG 素材套用到「可折疊的紙盒刀模」上，並呈現：

1. 完全展開的紙盒刀模
2. 從展開到組裝完成的折疊動畫
3. 組裝完成後的 3D 旋轉展示
4. 滑鼠拖曳旋轉
5. 滾輪縮放
6. 鍵盤控制旋轉
7. 觸控裝置拖曳與縮放

第一版應先建立一個「麵包餐盒」作為示範模型。

---

# 二、核心設計原則

最重要的要求：

**紙盒的各個部分絕對不能在旋轉、折疊或縮放時彼此散開。**

不能把每一片紙板當成獨立的 3D 物件隨意旋轉。

必須建立「父子階層＋折線旋轉軸」。

例如：

```text
Box
└── Bottom
    ├── Front
    │   └── FrontArtwork
    ├── Back
    │   └── BackArtwork
    ├── Left
    │   └── LeftArtwork
    ├── Right
    │   └── RightArtwork
    └── Lid
        └── LidArtwork
```

當 Bottom 移動或旋轉時，所有子物件必須同步移動。

當 Front 沿著折線旋轉時，Front 上面的所有 Artwork、透明窗、插舌等元素也必須一起旋轉。

---

# 三、技術方案

第一版使用：

* HTML
* CSS
* JavaScript
* SVG
* CSS 3D Transform

不要依賴大型 3D 引擎，例如 Three.js。

目標是：

* 可以直接雙擊 index.html 執行
* 不需要伺服器
* 不需要網路
* 不需要安裝 Node.js 才能使用展示器

如果開發階段需要 Vite 等工具，可以使用，但最後必須能輸出一個獨立的 dist 版本。

---

# 四、素材格式

支援以下格式：

## 1. SVG

優先支援。

SVG 可以包含：

* 向量圖案
* 文字
* 線條
* 圖形
* 透明區域
* 鏤空區域

SVG 不應該被強制轉成 JPG。

## 2. PNG

用於：

* 透明背景圖片
* 透明視窗
* 特殊材質
* 陰影

## 3. JPG / JPEG

可以使用於：

* 一般印刷圖片
* 照片
* 不需要透明的平面設計

JPG 本身不具有透明通道。

---

# 五、透明區域

紙盒可能具有透明視窗。

例如麵包餐盒正面：

```text
┌────────────────────┐
│                    │
│      麵包圖片      │
│                    │
│      ┌──────┐      │
│      │透明窗│      │
│      └──────┘      │
│                    │
└────────────────────┘
```

透明窗不能用 JPG 表示。

應使用：

* SVG mask / clipPath
* 或透明 PNG
* 或 SVG path

如果透明窗是真的鏤空，3D 展示時應該能看到後方內容，而不是看到一塊白色。

---

# 六、紙盒模型

第一個示範模型使用「可折疊麵包餐盒」。

不要求模型非常複雜，但必須包含：

* 底板
* 正面
* 背面
* 左側
* 右側
* 上蓋
* 插舌
* 至少數條折線
* 至少一個具有透明區域的示範面

範例展開結構：

```text
                 ┌───────────────┐
                 │     上蓋      │
                 │               │
                 └───────┬───────┘
                         │
                         │ 折線
┌────────┐ ┌─────────────┴─────────────┐ ┌────────┐
│ 左側板 │ │            背面           │ │ 右側板 │
└────────┘ └─────────────┬─────────────┘ └────────┘
                         │
                    ┌────┴────┐
                    │  底板   │
                    └────┬────┘
                         │
                    ┌────┴────┐
                    │  正面   │
                    └─────────┘
```

實際刀模不必完全按照此圖，但必須維持正確的幾何連接關係。

---

# 七、折線系統

每個可折疊紙片必須具有自己的 hinge（鉸鏈）。

例如：

```text
Front
│
│
│
└────────── hinge
```

程式資料結構應能描述：

```javascript
{
    id: "front",
    parent: "bottom",
    hinge: {
        x1: 0,
        y1: 0,
        x2: 300,
        y2: 0
    },
    openAngle: 0,
    closedAngle: 90
}
```

不要將旋轉中心固定在物件中心。

旋轉中心必須位於真正的紙盒折線。

---

# 八、展開與組裝

提供兩個主要狀態：

## 展開

所有紙片回到刀模平面：

```text
open = 0%
```

## 組裝完成

每一片紙板旋轉到指定角度：

```text
closed = 100%
```

中間可以使用動畫：

```text
0%
 ↓
25%
 ↓
50%
 ↓
75%
 ↓
100%
```

動畫必須讓各紙片保持原本的連接關係。

不能出現：

* 紙片飛走
* 接縫斷開
* 插舌漂浮
* 圖片與紙片分離

---

# 九、組裝動畫

提供：

「組裝」按鈕。

按下後：

```text
展開
→ 側板折起
→ 前後板折起
→ 插舌進入
→ 上蓋關閉
→ 完成
```

動畫速度可以設定。

例如：

```javascript
animationDuration = 2000;
```

另外提供：

「展開」按鈕。

可以從完成狀態反向播放。

---

# 十、3D 旋轉

組裝完成後，使用者可以自由觀看。

滑鼠：

* 左鍵拖曳：旋轉
* 滾輪：縮放

鍵盤：

* ↑：向上旋轉
* ↓：向下旋轉
* ←：向左旋轉
* →：向右旋轉
* R：恢復預設角度
* A：自動旋轉／停止

觸控：

* 單指拖曳：旋轉
* 雙指操作：縮放

---

# 十一、整體縮放與旋轉不能破壞結構

這一點非常重要。

使用者旋轉整個盒子時：

```text
Box
 ├── Bottom
 ├── Front
 ├── Back
 ├── Left
 ├── Right
 └── Lid
```

必須作為一個完整物件旋轉。

不能分別對每一面重新計算位置。

也就是：

```text
Box.rotation
```

控制整個盒子。

而：

```text
Front.rotation
Lid.rotation
Left.rotation
```

只負責該紙片相對於父物件的折疊角度。

---

# 十二、圖片與紙板的關係

每一片紙板的圖案必須成為該紙板的子物件。

例如：

```text
Front
├── FrontShape
├── FrontArtwork
└── TransparentWindow
```

當 Front 折疊：

```text
Front.rotate(90°)
```

以上三個元素必須一起旋轉。

不能：

```text
Front.rotate(90°)
Artwork.rotate(90°)
```

然後各自獨立計算位置。

這樣可以避免圖片在動畫中逐漸偏移。

---

# 十三、素材設定

把所有素材設定集中在一個設定檔。

例如：

```javascript
const packageConfig = {

    box: {
        width: 300,
        height: 180,
        depth: 80
    },

    artwork: {
        front: "images/front.svg",
        back: "images/back.svg",
        left: "images/left.svg",
        right: "images/right.svg",
        top: "images/top.svg",
        bottom: "images/bottom.svg"
    }

};
```

未來使用者只需要更換圖片，不必修改核心 3D 程式。

---

# 十四、支援完整 SVG 刀模

程式架構必須預留未來功能：

使用者可以提供一張完整 SVG 刀模。

例如：

```text
package-template.svg
```

其中包含：

* 紙板
* 折線
* 裁切線
* 圖案
* 文字
* 透明區域

未來可以將它轉換成：

```text
SVG 刀模
    ↓
解析紙片
    ↓
建立各紙片
    ↓
指定 hinge
    ↓
建立父子關係
    ↓
3D 組裝
```

第一版不一定需要自動解析完整刀模，但程式架構不能阻礙這項功能。

# 十九、程式品質要求

程式必須：

1. 模組化
2. 不把模型尺寸寫死在各個程式檔案
3. 不把圖片路徑寫死在 3D 引擎裡
4. 折線資料與紙板資料分離
5. 圖片與紙板建立父子關係
6. 旋轉中心由 hinge 決定
7. 整個盒子可以作為單一 root object 旋轉
8. 所有尺寸使用同一套座標系統
9. 縮放只改變 camera / viewport，不重新計算紙盒幾何
10. 不使用會造成長時間運作漂移的反覆累積 transform 計算

---

# 二十、驗收條件

第一版完成後必須符合：

### A. 展開

按「展開」：

* 所有紙片回到正確刀模位置
* 所有折線位置正確
* 圖案與紙板完全對齊

### B. 組裝

按「組裝」：

* 紙盒可以從平面逐步折成 3D
* 每片紙板都沿正確折線旋轉
* 紙片不會分離
* 圖案不會漂移
* 插舌位置保持正確

### C. 3D

完成組裝後：

* 可以自由 360°旋轉
* 可以縮放
* 所有紙片保持相對位置
* 不會因旋轉或縮放而散開

### D. 透明

正面透明窗：

* 透明區域真的透明
* 可以看到後方內容
* 旋轉時透明區域跟著紙板移動

### E. 反向動畫

由組裝完成按「展開」：

* 可以平順回到完整刀模
* 所有紙片仍然保持連接

# 二十二、最重要的開發原則

不要先做一個「看起來像 3D 的盒子」就結束。

這個專案真正的核心是：

**「具有實際拓撲關係的紙盒模型。」**

也就是：

```text
紙片
 ↓
折線
 ↓
父子關係
 ↓
局部旋轉
 ↓
整體旋轉
 ↓
展開／組裝動畫
```

只要這個資料結構建立正確，未來就可以從簡單六面盒逐步增加到非常複雜的包裝盒，而不需要重新設計整個系統。

請先完成「麵包餐盒」示範模型，再開始設計可匯入其他 SVG 刀模的架構。
